# 专注小屋 - 学习计时 App

一个功能齐全的学习计时应用，包含番茄钟计时、自习室、论坛、知识科普、勋章奖励和小屋装扮系统。

## 功能

- **登录页** - 带动效的欢迎界面，选择头像与昵称
- **计时** - 番茄钟专注/休息模式，多种预设，可自定义时长
- **自习室** - 8 间自习室，加入或创建，实时专注人数
- **论坛** - 6 篇热帖，发帖、评论、点赞、标签筛选
- **知识科普** - 10 篇精选文章，搜索与分类浏览
- **勋章墙** - 12 枚勋章，累计学习解锁，主页展示
- **设置中心** - 个人资料、小屋、通知、主题、计时偏好、学习目标等可点进子页面
- **小屋系统** - 8 种家具，8 种颜色，积分兑换
- **小猫动画** - 小猫在房间里慢慢走动

## 启动

```bash
npm install
npm run dev
```

浏览器打开 http://localhost:5173

## 技术栈

- React 19 + TypeScript + Vite
- Tailwind CSS 4
- Zustand（状态持久化到 localStorage）
- React Router
